[CENTER][SIZE=6][COLOR=#ffcc00][B]SethomeX v1.0.7 - Folia Support, Config Autoupdater, Performance Optimizations & Adventure API Modernization[/B][/COLOR][/SIZE]

[LIST]
[*] [COLOR=#ffcc00][B]Folia & Multi-Platform Support:[/B][/COLOR] Introduced a dynamic scheduler wrapper that automatically detects your server engine. Fully supports [B]Folia[/B] (regional multithreading), [B]Paper[/B], and [B]Spigot[/B] out of the box with zero configuration required. All task countdowns, particles, claims integrations, and player teleports have been optimized to run safely on regional threads via Folia-native schedulers and asynchronous teleportation.
[*] [COLOR=#ffcc00][B]Automatic Configuration & Resource Updater:[/B][/COLOR] No more deleting files! Introduced an automatic configuration updater that scans and merges any new settings, translations, or items from `config.yml`, `messages.yml`, and `gui.yml` directly into your existing files on disk, fully preserving user changes and file comments (uses Spigot 1.18+ comments API).
[*] [COLOR=#ffcc00][B]Configurable Spectator Preview settings:[/B][/COLOR] The spectator preview duration and toggling are no longer hardcoded! Added `teleport.preview.enabled` and `teleport.preview.duration` under `config.yml` to fully manage the preview module.
[*] [COLOR=#ffcc00][B]Custom Welcome Message Durations:[/B][/COLOR] Personalize how long welcome titles and subtitles stay on visitor screens. Timing values are now configurable via `social.welcome-message` with `fade-in-ms`, `stay-ms`, and `fade-out-ms` options.
[*] [COLOR=#ffcc00][B]Localized Preview Error cue:[/B][/COLOR] Added `gui.error-preview-disabled` inside `messages.yml` showing a clear, customizable message and playing a warning sound when players attempt to preview a home when the feature is disabled.
[*] [COLOR=#ffcc00][B]Aesthetic Config Documentation:[/B][/COLOR] Fully updated particle list and styles in `config.yml` comments to include all premium styles (`TORNADO`, `PROGRESSIVE_RING`, `BEACON`) and materials (`DRIP_WATER`, `CLOUD`, `SOUL_FIRE_FLAME`).
[*] [COLOR=#ffcc00][B]Dynamic Home Limits:[/B][/COLOR] Added support for dynamic numerical limit permissions (e.g., `sethomex.limit.<number>`). The plugin automatically detects these permissions and grants players the highest limit value found, bypassing the need to define fixed groups in `config.yml`.
[*] [COLOR=#ffcc00][B]Live Cosmetic Previews:[/B][/COLOR] When selecting cosmetics in the `/home effects` menu, players can now preview them immediately. Selecting particles/styles animates them around the player for 1 second, and selecting sounds plays the sound effect directly to the player.
[*] [COLOR=#ffcc00][B]Physical Compass Pointer:[/B][/COLOR] Added the `/home compass <home_name>` (and `/home target`) command. Players can now direct their physical compass needle towards any of their home locations, making navigation more immersive.
[*] [COLOR=#ffcc00][B]Smart Safe Teleport (Smart Safe TP):[/B][/COLOR] If a home destination is obstructed or hazardous (e.g., solid block, lava, or void), the teleport system scans a 3-block radius for the nearest safe block and teleports the player there with a warning message.
[*] [COLOR=#ffcc00][B]Likes Count SQL Bugfix:[/B][/COLOR] Fixed a database bug where the home likes count was reset to 0 in memory/cache upon player connection or toggling favorites due to missing SQL columns in queries.
[*] [COLOR=#ffcc00][B]Spectator Preview Safety:[/B][/COLOR] Resolved a security exploit where players disconnecting during a spectator home preview could reconnect in spectator mode at the preview location. Player state is now persisted via PersistentDataContainer (PDC) and safely restored upon join.
[*] [COLOR=#ffcc00][B]Multiverse Portal Frame Support:[/B][/COLOR] Fixed a portal detection issue where physical frame blocks located in secondary worlds (loaded after the plugin initialized) would not detect destruction. Portal coordinates are now calculated dynamically.
[*] [COLOR=#ffcc00][B]Redefine Home Casing Fix:[/B][/COLOR] Redefining an existing home now correctly preserves its original casing in the database to prevent duplicate entries in case-sensitive environments like SQLite.
[*] [COLOR=#ffcc00][B]GUI Drag Exploit Blocker:[/B][/COLOR] Added an `InventoryDragEvent` listener to block dragging items in custom inventories, preventing client-side glitches and GUI item injection/stealing exploits.
[*] [COLOR=#ffcc00][B]World/Dimension Limits:[/B][/COLOR] Restrict the number of homes players can set in specific worlds/dimensions (e.g., max 1 in Nether, 0 in End) configured in `config.yml`. Supports OP and permission-based bypass (`sethomex.bypass.world-limit`).
[*] [COLOR=#ffcc00][B]Advanced Co-ownership & Roles:[/B][/COLOR] Expand the trust system to support two roles: `Visitor` (teleport-only) and `Co-Owner` (can edit description, welcome message, fee, category, and invite guests, but cannot delete). Manage roles directly inside the `HomeGUI` trust manager.
[*] [COLOR=#ffcc00][B]Physical Teleport Signs:[/B][/COLOR] Allow players with `sethomex.sign.create` to create interactive teleportation signs (first line `[SethomeX]`). Right-clicking the sign triggers a warmup teleportation to the specified home.
[*] [COLOR=#ffcc00][B]Warmup Implosion Effect:[/B][/COLOR] A brand new immersive teleport style (`IMPLOSION`). Creates a rotating cylinder of particles that progressively shrinks from a 3-block radius to a dense point on the player at the moment of teleportation.
[*] [COLOR=#ffcc00][B]Home Category Command & GUI Improvements:[/B][/COLOR] Fully redesigned the `/home category` (and `/home folder`) command. Added complete Tab Completion (for the subcommands, player homes, and existing categories + `none` to remove it). Fixed a bug where category names containing spaces were cut off when using the command. Added safety limits in both the command and GUI input to truncate category names to 16 characters, preventing database SQL exceptions.
[*] [COLOR=#ffcc00][B]Back Button Lifecycle Fix:[/B][/COLOR] Resolved a race condition where clicking the "Back" button in the admin view failed to transition inventories due to player GUI states being prematurely cleared on inventory close.
[*] [COLOR=#ffcc00][B]Cornerless Portal Frames Support:[/B][/COLOR] Portal validation now allows frames to be constructed without the 4 optional corner blocks, fully supporting standard Nether Portal shapes without outputting the "Invalid frame" error.
[*] [COLOR=#ffcc00][B]Sign Teleport Double-Trigger Fix:[/B][/COLOR] Fixed an issue where right-clicking interactive signs triggered the teleport event twice (once for the main hand and once for the off-hand).
[*] [COLOR=#ffcc00][B]Adventure API Modernization:[/B][/COLOR] Migrated the player respawn notification logic and `/home list` formatting from deprecated Bukkit/Bungee chat APIs to the modern Kyori Adventure API, resolving deprecation warnings and ensuring full compatibility with Paper 1.21.4+.
[*] [COLOR=#ffcc00][B]Database Indexing Optimizations:[/B][/COLOR] Added missing database indexes on `sethomex_trusts(guest_uuid)` and `sethomex_visits_log(owner_uuid, home_name)` to prevent slow Full Table Scans and filesorts, significantly improving TPS on high-traffic servers.
[*] [COLOR=#ffcc00][B]Thread-Safe Player Name Cache:[/B][/COLOR] Introduced a memory cache for player name lookups. Prevents blocking synchronous `Bukkit.getOfflinePlayer(uuid).getName()` network/disk requests on the main thread during GUI rendering, command executing, and map updates.
[*] [COLOR=#ffcc00][B]Complete Command Localization:[/B][/COLOR] Externalized and localized all remaining hardcoded user-facing messages from `/home` subcommands (welcome messages, descriptions, fees, moderating, folder sharing, and administration info) directly into `messages.yml` for easy customization.
[/LIST]
