[SIZE=5][B][COLOR=#FFD700]📦  1. INSTALLATION[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]
[COLOR=#D3D3D3][LIST=1]
[*] Download the latest [B]SethomeX.jar[/B] file.
[*] Place it into your server's [I]/plugins/[/I] folder.
[*] (Optional) Ensure you have [B]PlaceholderAPI[/B] for visual integration.
[*] Restart your server to generate system configurations and initial databases.
[*] Edit [B]config.yml[/B] to link MySQL or fine-tune aesthetic parameters.
[/LIST][/COLOR]

[SIZE=3] [/SIZE]

[SIZE=5][B][COLOR=#FFD700]⚙️  2. CONFIGURATION BREAKDOWN[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]

[B][COLOR=#FFFFFF]Data Storage (Database Engine):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]database.type:[/COLOR][/B] [COLOR=#AAAAAA]Choose between SQLITE (single server local file) or MYSQL (multi-proxy sync).[/COLOR]
[*] [B][COLOR=#FFD700]database.mysql.pool.maximum-size:[/COLOR][/B] [COLOR=#AAAAAA]Configures high-end HikariCP performance tuning (default 10).[/COLOR]
[*] [B][COLOR=#FFD700]use-ssl:[/COLOR][/B] [COLOR=#AAAAAA]Native SSL encryption for external database connections.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Teleport Logic & Cooldowns:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]teleport.cooldown:[/COLOR][/B] [COLOR=#AAAAAA]Warmup timer duration in seconds. Set to 0 for instant movement.[/COLOR]
[*] [B][COLOR=#FFD700]teleport.cancel-on-move:[/COLOR][/B] [COLOR=#AAAAAA]Stops teleportation if the player changes coordinates.[/COLOR]
[*] [B][COLOR=#FFD700]teleport.cancel-on-damage:[/COLOR][/B] [COLOR=#AAAAAA]Interrupts active warmup sequence if incoming player damage occurs.[/COLOR]
[*] [B][COLOR=#FFD700]teleport.cancel-in-combat:[/COLOR][/B] [COLOR=#AAAAAA]Prevents triggering or finalizing warps while in engaged combat states.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Tiered Limit System:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]limits.default:[/COLOR][/B] [COLOR=#AAAAAA]Maximum homes for basic tier players (e.g. 3).[/COLOR]
[*] [B][COLOR=#FFD700]limits.<rank_group>:[/COLOR][/B] [COLOR=#AAAAAA]Assign higher caps to specific permission nodes ([I]sethomex.limit.vip[/I]). The engine automatically prioritizes the highest granted numeric cap.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]VFX (Visual Effects Engine):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]effects.countdown.particle:[/COLOR][/B] [COLOR=#AAAAAA]Select the primary visualization (FLAME, PORTAL, ENCHANT, CHERRY_LEAVES, WITCH, etc).[/COLOR]
[*] [B][COLOR=#FFD700]effects.countdown.style:[/COLOR][/B] [COLOR=#AAAAAA]Controls the procedural math shape: SPIRAL (upward helix), RING (dual planar circles), SHIELD (protective shell bubble).[/COLOR]
[*] [B][COLOR=#FFD700]effects.countdown.sound:[/COLOR][/B] [COLOR=#AAAAAA]Aural count sound triggered on every descending interval tick.[/COLOR]
[*] [B][COLOR=#FFD700]effects.success.particle:[/COLOR][/B] [COLOR=#AAAAAA]Landing burst effect upon arriving at destination coords.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]GUI Configuration (Menu Personalizer):[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]gui.title:[/COLOR][/B] [COLOR=#AAAAAA]Inventory header text. Supports legacy & hex color codes.[/COLOR]
[*] [B][COLOR=#FFD700]gui.fill-empty-slots:[/COLOR][/B] [COLOR=#AAAAAA]Toggles aesthetic pane fillers for modern aesthetics.[/COLOR]
[*] [B][COLOR=#FFD700]gui.icon-selector.icons:[/COLOR][/B] [COLOR=#AAAAAA]Full customized pool of Material types visible in the in-game icon modifier utility.[/COLOR]
[/LIST]

[B][COLOR=#FFFFFF]Security Matrix:[/COLOR][/B]
[LIST]
[*] [B][COLOR=#FFD700]safety.check-safe-destination:[/COLOR][/B] [COLOR=#AAAAAA]Blocks warping if targeted destination block transitions to harmful state (lava, void, block obstruction).[/COLOR]
[*] [B][COLOR=#FFD700]safety.prevent-unsafe-sethome:[/COLOR][/B] [COLOR=#AAAAAA]Strict rule ensuring players must stand on solid material foundations when generating saved coordinates.[/COLOR]
[/LIST]

[SIZE=5][B][COLOR=#FFD700]📊  3. PLACEHOLDERAPI INTEGRATION[/COLOR][/B][/SIZE]
[COLOR=#888888]────────────────────────────────────────────────────[/COLOR]
[COLOR=#AAAAAA]Expose SethomeX stats to your UI, Scoreboards, or Chat formatting engines:[/COLOR]

[LIST]
[*] [B][COLOR=#FFD700]%sethomex_count%[/COLOR][/B] [COLOR=#AAAAAA]— Total current homes created by the player.[/COLOR]
[*] [B][COLOR=#FFD700]%sethomex_limit%[/COLOR][/B] [COLOR=#AAAAAA]— Current resolved maximum limit based on their rank.[/COLOR]
[*] [B][COLOR=#FFD700]%sethomex_remaining%[/COLOR][/B] [COLOR=#AAAAAA]— Amount of free home slots left to utilize.[/COLOR]
[*] [B][COLOR=#FFD700]%sethomex_limit_reached%[/COLOR][/B] [COLOR=#AAAAAA]— Returns true/false condition based on current capacity.[/COLOR]
[/LIST]
